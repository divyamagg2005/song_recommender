# **App Name**: StoryMuse

## Core Features:

- Input Description: Users can enter a description of their photo or scene to generate a relevant song suggestion. There is also an option for users to upload the photo. This app provides google adsense integration
- AI-Powered Song Recommendation: AI analyses the image description and user's selected music preferences. AI Tool generates the perfect song recommendations. It considers genre and the 'latest or old' preference of user in its song recommendation.
- Song Presentation: Display song recommendation clearly with links to listen on major platforms (Spotify, Apple Music, YouTube).
- Google Adsense integration: Ads will appear within the Song Recommendation, at the footer of the page and possibly a banner at the header

## Style Guidelines:

- Primary color: Light teal (#A0CED9) for a calm and creative feel.
- Secondary color: Soft beige (#F2EBD3) for backgrounds and content areas.
- Accent: Coral (#FF7F50) for interactive elements and call-to-actions.
- Clean and modern typography to ensure readability and a professional look.
- Simple and intuitive icons for easy navigation and understanding.
- Clean, single-page layout for easy user flow and accessibility.
